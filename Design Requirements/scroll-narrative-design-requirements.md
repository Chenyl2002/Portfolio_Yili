# 滚动叙事作品集网站设计需求文档

## 项目目标

将个人作品集网站重构为一个“人物叙事驱动”的互动网页。页面不再采用传统作品集排版，而是像一段可滚动的网页动画短片：用户通过向下滚动，镜头依次经过人物、手机、工牌正面、工牌背面，并在每个物件上展示对应内容。

原网站中的文字、项目内容、简历信息、联系方式、设计文档内容保持一致，只改变呈现方式与交互动画。

## 核心叙事流程

### 1. 开场：人物登场

第一屏出现原创男性二次元角色立绘。人物旁边展示：

- 陈宜理
- GAME LEVEL & NARRATIVE PLANNING
- 首页介绍文案
- 四个个人优势：跨学科设计基础、UE5 落地能力、项目统筹与协作、资深玩家洞察

这一屏的重点是“我是谁”，项目内容不在开场抢占主视觉。

### 2. 第一次滚动：手机飞出

用户向下滚动时，人物手中的手机飞出并放大，镜头转入手机界面。

手机屏幕中展示：

- 游戏项目展示
- 项目筛选按钮
- 四个项目：破碎之家、破冰启航、山中古刹、Gamified Moston
- 项目详情弹窗
- 设计文档区域与 PDF 预览入口

### 3. 第二次滚动：手机滑走，镜头转向工牌

继续向下滚动，手机从画面滑走，镜头转向人物身上的工牌。工牌放大后成为简历信息容器。

工牌正面展示：

- 简历展示
- Profile
- 头像
- 姓名、角色、电话、邮箱、学校信息
- 项目经历
- 技能特长
- 游戏经历

### 4. 第三次滚动：工牌翻面

继续向下滚动，工牌执行 3D 翻转动画，显示工牌背面。

工牌背面展示：

- 关于我
- 联系方式
- 邮箱
- Bilibili 主页
- 合作、实习、校招机会相关文案

## 视觉风格

整体方向：二次元游戏风 + 作品集 PV + 轻幻想科技 UI。

关键词：

- 原创二次元男性角色立绘
- 游戏角色档案
- 手机界面放大转场
- 工牌 / 身份卡 / 任务证件
- 3D 翻转
- 视差滚动
- 发光描边
- 粒子光效
- 镜头推进
- HUD UI
- 半透明玻璃质感
- 蓝绿色科技光 + 金色点缀

避免：

- 传统简历网页感
- 普通卡片堆叠
- 项目一开始就占主视觉
- 过度模糊导致文字不可读
- 动效太多但没有叙事逻辑

## 页面结构

1. `Hero Character Scene`：人物 + 姓名 + 个人简介 + 四个优势
2. `Phone Project Scene`：手机屏幕 + 项目展示 + 设计文档
3. `Badge Resume Scene`：工牌正面 + 简历信息
4. `Badge Contact Scene`：工牌背面 + 关于我 + 联系方式

## 交互需求

- 滚动驱动动画，而不是单纯 hover。
- 每一段滚动对应一个明确镜头变化。
- 项目卡仍可点击打开详情弹窗。
- 设计文档仍可点击预览 PDF。
- 手机端需要简化动画，但保留叙事顺序。
- 用户不滚动时，页面也应停在稳定、可阅读的画面上。

## 验收标准

- 第一屏能明确看到人物、姓名、个人定位，而不是项目。
- 滚动后手机飞出并承载项目内容。
- 再滚动后工牌放大并承载简历内容。
- 最后工牌翻面展示联系方式。
- 原网站所有核心内容完整保留。
- 桌面端动效顺滑，移动端不横向溢出。
- 文字在所有阶段都清晰可读。
